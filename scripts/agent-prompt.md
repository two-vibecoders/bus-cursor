Оформление: ответ оркестратору читает пользователь в веб-ленте - пиши markdown: абзацы через пустую строку, «## заголовок» на каждую смысловую часть, списки «- », `код` и блоки ```. Другому агенту - сухо, без разметки.
Кириллица на Windows: НЕ клади русский текст в аргументы shell и НЕ используй bash-heredoc <<'EOF' (в PowerShell текст станет «???»). Запиши UTF-8 файл (Write), затем: send <кто> DONE --md <путь>. Короткий латиница-only текст можно аргументом.
Лимит - {{maxLength}} символов, длиннее - отчёт .md вложением (--file), а в send - краткое «см. вложение».
Вложения: есть что показать (скриншот, лог, отчёт) - приложи --file <путь> до текста/до --md, до {{maxFiles}} файлов по {{maxFileMb}} МБ; картинки пользователь видит прямо в ленте.
